run bad apple-fier locally

if the website is lagging, you can run it on your own device instead.

1. install python (pc only)

if you're on windows, install python first.

python.org/downloads

2. download bad apple-fier

pick whichever is easier:

  • zip download
  • github repository

3. extract it

extract everything into one folder.

4. run it

open a terminal in that folder and run:

python -m http.server

then open http://localhost:8000 in your browser.

5. mobile

i recommend quickedit because it can run bad apple-fier.

extract the files, open index.html, then press run.

notes

  • don't move any files after extracting them.
  • if something is missing, extract the zip again.
  • running it locally is usually much faster than the website.
